# PCM - Multimedia Authoring - Image Search Application

### Project Description: 
Project developed for the Multimedia Content Production course, featuring an interactive web application for searching and filtering digital photos by keywords or color histograms. Built with HTML5, JavaScript, and XML, the app enables users to browse images from 14 categories and filter by 12 predefined colors using advanced pixel analysis.

### Key Features

#### Keyword Search
- Select a category to view the first 30 matching images.
  
#### Color Search
- Employs a **12-color histogram** for pixel-level analysis.
- Enables users to search for images based on color similarity.

#### Interactive Color Picker
- Visual color selection with colored circles.
- Enhances usability and search precision.

#### Grid View Display
- Images shown in a structured, user-friendly grid layout.

#### Advanced Color Processing
- Custom thresholds per color for more accurate histograms.
- Pixel-wise color computation for robust matching.

#### Local Storage Integration
- Stores pre-processed histogram data in `localStorage` for improved performance.

#### Additional Features
- Color-based search without category constraints.
- Save functionality for images from any search result.

---

### Technologies Used
- **HTML5** – App structure and layout  
- **JavaScript** – Core logic, color processing, and UI interactivity  
- **XML** – Data storage and retrieval  
- **LocalStorage** – Persistent, client-side caching for faster access
