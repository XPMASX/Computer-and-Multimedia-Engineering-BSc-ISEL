# IPM - Human Computer Interaction - ISEL Website Usability Testing

### Project Description: 
Conducted a comprehensive usability evaluation of a redesigned ISEL university website prototype (developed in Figma) to address pain points in the existing system. The focus was on improving efficiency, learnability, and user satisfaction for 2nd/3rd-year engineering students.

### Key Contributions:

- **User-Centered Redesign:**  
  - Simplified navigation (reduced from 59 pages to 9 core sections).  
  - Added direct access to critical info (e.g., schedules, events, faculty contacts) from the homepage.

### Methodology:

- Remote usability testing with **10 participants** via Google Forms.  
- Mixed-method analysis:  
  - Task success rates  
  - Likert-scale feedback  
  - SUS (System Usability Scale)

### Results:

- **92.75 SUS score** (vs. 68 for the original site).  
- **70% adoption rate** for new features (e.g., one-click access to course plans).  
- Identified key pain points (e.g., scroll-heavy homepage) and proposed fixes (e.g., prioritized content layout).

###  Technologies & Tools:

- **Prototyping:** Figma  
- **Testing:** Google Forms, SUS metrics  
- **Analysis:** Descriptive statistics, qualitative feedback coding

### Key Takeaways:

- Validated the prototype’s effectiveness (**90% task completion**) and efficiency (reduced navigation steps).  
- Highlighted the importance of **onboarding** (users overlooked some features due to lack of initial exploration).
