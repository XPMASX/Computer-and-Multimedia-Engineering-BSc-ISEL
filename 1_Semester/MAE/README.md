# Applied Mathematics to Engineering - Circuit Trajectory Simulator

## Project Description  
Project developed for the Mathematics Applied to Engineering course, simulates a car moving along a custom-designed circuit. The program ensures the object follows a parametrized path composed of at least three distinct segments, including straight, parabolic sections and elliptical curves. Key features include adjustable speeds, dynamic orientation of the object, and real-time velocity display. Built with Python and Pygame, the project demonstrates parametric equations and trajectory modeling.
