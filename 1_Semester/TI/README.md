# TI - Information Technologies - Programming Fundamentals  

### Project Description:  
A collection of Java programming exercises developed for the Information Technologies course, 
covering core programming concepts including loops, methods, arrays, and PPM image generation. The projects demonstrate proficiency in algorithmic thinking, problem decomposition, and graphical output generation.  

---

### Key Components  

#### **1. Loop Structures**  
- **Number Range Display** (`TP2_01_MostrarNumerosEntre`):  
  Prints numbers between two user-input values with line breaks every 10 numbers.  
- **Capitalization Formatter** (`TP2_02_CapitalFirstChar`):  
  Converts text to lowercase except for the first letter of words with ≥3 characters.  
- **Pattern Generation** (`TP2_03_TrianguloCardinais`):  
  Creates centered triangle patterns using `#` symbols.  

#### **2. Method Implementation**  
- **Digit-to-Word Converter** (`TP2_05_EscreveDigitos`):  
  Uses helper methods (`getDigitoEmString`, `getNumDigitos`) to print digits as words (e.g., "2490" → "dois, quatro, nove, zero").  
- **PPM Image Generator** (`TP2_06_DesenhaEmPPM`):  
  Dynamically creates PPM images with rectangles/triangles via user input, leveraging methods like `drawRectangle` and `drawTriangle`.  

#### **3. Graphical Applications**  
- **Flag Generator** (`TP2_07_DesenhaBandeirasEmPPM`):  
  Renders national flags (Portugal, Spain, Germany, etc.) with proportional dimensions and accurate colors using PPM format.  
- **Color Gradient Tool** (`TP2_08_DesenhaDegradeEmPPM`):  
  Generates horizontal color gradients between user-specified RGB values.  

#### **4. Array Operations**  
- **Merge Arrays with Unique Values** (`TP2_09_MergeWithoutRepetitions`):  
  Combines two arrays while removing duplicates (e.g., `[1,2,3] + [3,4,5] → [1,2,3,4,5]`).
