# AAV - Animation in Virtual Environments - Cowboy Game
 
### Project Description: 
A cowboy-themed game developed in Unity for the Animation in Virtual Environments course, with the goal of learning the fundamentals of game development, 
including player movement, physics interactions, AI behavior, lighting, particle effects, audio, and animation. The project explores core concepts like scripting, UI design, and environmental effects.

### Key Features

- **Player Mechanics:**  
  - Responsive cowboy movement (walking, running, aiming, shooting)  

- **AI Behavior:**  
  - NPCs with patrol, chase, and reaction logic (e.g., bandits, townsfolk)

- **Environmental Effects:**  
  - Particle systems (blood splatter, gun smoke, campfire effects)

- **Audio & Animation:**  
  - Sound effects (gunshots, footsteps, ambient)  
  - Character animations (idle, combat)

- **UI/UX Design:**  
  - Health bars and quest log 
  - Minimap

### Technologies Used

- **Unity** (Game Engine)  
- **C#** (Game Logic)
