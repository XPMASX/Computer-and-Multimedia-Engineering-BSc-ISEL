# IAV - Interaction in Virtual Environments - Endless Runner Game

### Project Description: 
A virtual environment project developed for the Virtual Environments Interaction course, combining procedural generation, machine learning, and human-machine interaction
to create an immersive driving simulation. Players control a car either manually or via an AI agent, using sound inputs (whistles for braking, claps for traffic light control)
to navigate an infinitely generated track with dynamic obstacles.

###  Key Features

- **Procedural Track Generation:**  
  Dynamically creates endless tracks using Bézier curves and B-splines with Unity’s Path Creator asset.

- **AI-Powered Autonomous Driving:**  
  Trains an ML agent to navigate obstacles and recover from errors using reinforcement learning (ML-Agents).

- **Sound-Based Interaction:**  
  - Whistles trigger braking.  
  - Claps switch traffic lights between red and green.

- **Dynamic Obstacles:**  
  Includes pedestrians and traffic signals to enhance gameplay difficulty.

- **Leaderboard System:**  
  Tracks and displays top player scores.

### Technologies Used

- **Unity** for game development  
- **C#** for scripting  
- **ML-Agents** for AI training
