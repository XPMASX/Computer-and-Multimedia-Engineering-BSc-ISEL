# SMI - Internet Multimedia Systems - MediaWiki Implementation

### Project Description: 
Developed for the Internet Multimedia Systems course, this project involved implementing a MediaWiki-based CMS to create a platform similar to Wikipedia, but focused on satirical and esoteric content. The system allows users to create, edit, and manage articles, with features like user authentication, role-based permissions, and multimedia integration.

### Key Features

- **User Authentication:**  
  - Login, logout, and registration with email confirmation.
  
- **Role-Based Access Control:**  
  - Guest, User, Supporter, Administrator roles.
  
- **Article Management:**  
  - Creation, editing, protection levels, and geolocation tagging.
  
- **Multimedia Support:**  
  - Images, videos with thumbnails and captions.
  
- **Search Functionality:**  
  - Categorized content display.

### Technologies Used

- **PHP**, **MySQL** for backend and database  
- WYSIWYG editor for content formatting  
- Regular expressions for input validation
