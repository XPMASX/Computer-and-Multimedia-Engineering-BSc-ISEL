# DAM - Mobile Applications - Video Game Collection Tracker

### Project Description: 
A mobile application developed for the Mobile Applications course, enabling users to log, rate, and review video games while tracking their gaming history. The app integrates with the IGDB API to fetch game data and uses Firebase for real-time updates.

### Key Features

- **Game Logging and Review System:**  
  Allows users to log, rate, and review their video games.
  
- **Integration with IGDB API:**  
  Fetches detailed game information.
  
- **Firebase Integration:**  
  Used for authentication and data storage, enabling real-time updates.

### Technologies Used

- **Kotlin** for Android development  
- **Firebase** for backend services  
- **IGDB API** for game data
